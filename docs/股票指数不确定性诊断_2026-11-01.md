# 股票与指数不确定性诊断 · 2026-11-01

常规 `market-validate` 报告版本9增加固定路径的配对块自助诊断。目的是揭示样本与结果的不稳定程度，不自动增加指标、改阈值或挑选模型。沿用原始模型、候选、冻结训练、共同可预测日期及费用口径；规则模式 `--execution-only` 不增加此项，页面也不增加重采样计算。

## 统计口径

| 输出 | 样本与正值含义 | 固定块长度 | 展示门槛 |
| --- | --- | --- | --- |
| `evidence.brier_improvement_uncertainty` | 同一成熟日期上原模型Brier减候选Brier，正值表示候选误差较小 | 1、3、5个已按预测周期隔开的配对观测 | 至少20个配对观测且至少4倍块长度 |
| `execution.return_uncertainty` | 三档费用各自的候选净累计收益减原模型净累计收益 | 5、10、20个会话净收益 | 至少60会话、至少4倍块长度，且双方各至少5笔闭合交易 |

Brier样本与既有HAC诊断完全一致：先取双方共同成熟日期，再按预测周期隔开，不将末端未成熟预测纳入质量评估。收益则从双方共同预测起点估值到区间末日，不按未来标签是否成熟删去尾部；初始成交费用也保留在净日收益中。资金权益先除以各自初始现金。

每个块长度固定种子20261101、1000次非循环移动块抽样，截取到原样本长度，给出2.5%和97.5%分位点。两个账户始终共用抽样索引，再分别复合日收益；不把独立抽样误当配对比较。

`insufficient`表示样本不足，`sparse_trades`表示闭合交易未达门槛，`degenerate`表示重采样统计量没有变化，`unstable`表示计算溢出等非有限结果。上述状态不输出有效区间端点；输入非有限或日期/权益不对齐直接拒绝，不静默丢弃会话。常数的正改善也不包装成确定优势。

## 解释边界

这些是逐块长度的点态95%条件诊断区间，**没有区间多重比较校正**，不能挑最有利的块长度或以不含0为由宣称稳定有效。既有HAC/Bonferroni字段保留原定义，不能借其校正解释新增区间。

收益再抽样只重排固定账户净收益路径，不重新拟合预测、不重放订单、整手、资金与容量约束，因此不是完整交易策略的生成分布。各5笔闭合交易只是保守展示门槛，不是统计功效或区间有效性保证。配对顺序相关、非平稳、样本选择和同一留出期反复查看的问题仍存在。

这项工作没有完成独立概率校准、未来未使用样本验证、公司行动或实际成交证明。当前资金边界见[资金账户记录](资金账户情景验证_2026-11-01.md)，完整样本来源见[完整清单记录](完整样本验证记录_2026-10-31.md)。

## 重现

使用已有不可覆盖快照，无需重新抓取行情：

```powershell
uv run python run.py market-validate --manifest output/capital-model-snapshot-20261101/manifest.json --output output/results/capital-model-uncertainty-new.json
```

新环境先按[模型资金示例](capital-model-validation-plan.json)运行 `market-snapshot` 生成本地快照。输入、源码及参数指纹随报告保存；输出目录不入库，换环境需要自行准备数据。旧版资金报告保留原版本与历史结论，不视为本轮重算记录。
