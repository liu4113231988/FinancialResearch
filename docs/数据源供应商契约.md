# 数据源供应商契约（公开抓取口径）

产品口径：**继续使用公开抓取，不采购合规数据源**。公开接口没有 SLA，以下契约
描述本系统依赖的端点、字段与失败语义；源站结构变化时会在取数层显式报错
（`ProviderContractError`，见 `src/market_research/errors.py`），不会静默算出
错误结果。

机器可读的契约镜像在 `src/market_research/data/provenance.py:CONTRACTS`，新增
数据源时两处同步更新。

## 端点与字段假设

| 来源键 | 端点 | 关键字段 | 用途 |
| --- | --- | --- | --- |
| `fund_nav` | `akshare fund_open_fund_info_em(indicator="累计净值走势")` | 日期、累计净值 | 累计净值序列（兼容/对照口径） |
| `fund_unit_nav` | `akshare fund_open_fund_info_em(indicator="单位净值走势")` | 日期、单位净值 | 总回报构造 |
| `fund_cum_return` | `akshare fund_open_fund_info_em(indicator="累计收益率走势")` | 日期、累计收益率（%） | 总回报校准锚点（月频） |
| `index_sina` | `akshare stock_zh_index_daily` | `date`、`close` | 宽基/市值/风格指数日线 |
| `index_sw` | `akshare index_hist_sw(period="day")` | 日期、收盘 | 申万一级行业指数日线 |
| `csindex_pe` | `akshare stock_zh_index_value_csindex` | 日期、`市盈率2` | 宽基估值分位 |
| `csindex_dividend` | `akshare stock_zh_index_value_csindex` | 日期、`股息率2` | 宽基股息率（%） |

字段校验在 `data/provenance.py:require_columns`：
- 缺列、列改名、返回空表 → 抛出 `ProviderContractError`，错误信息包含来源键、
  实际列与端点。
- 单个指数结构异常不会被 `fetch_pe_panel` / `fetch_dividend_panel` 的逐标的
  异常处理吞掉，会中断本次抓取。
- 候选池全部失败时 `fetch_universe` 显式抛错（部分失败仍按 `missing_assets`
  进入数据质量标记，见 P2-28）。

## 限流、重试与降级

- 主动限流：`FIL_HTTP_MAX_RPS`（默认 `8`，单位请求/秒，全进程共享；
  `<=0` 关闭）。
- 重试：`data/http.py:_retry` 对网络/超时类异常按 `wait × 2^i` 指数退避
  （上限 30 秒，含抖动），默认 4 次；`ValueError`/`KeyError`/`TypeError`/
  `AttributeError`/`ProviderContractError` 属于编程或契约错误，**不重试**。
- 降级：`_cached` 在抓取失败且旧缓存口径仍匹配时返回旧数据，并挂
  `stale` / `source_error`；统一汇总为 `data_quality.status = degraded`。
  净值总回报口径失败默认拒绝（`FIL_NAV_DEGRADED_POLICY=reject`）。
- 溯源：每次抓取记录来源、端点、抓取时间、成功/降级/错误，进入
  `data_quality.provenance`，随 meta / 报告 / Web 展示。

## 已知覆盖边界

- csindex 官方文件只保留最近约一个月，历史靠每日累积（`panels._accumulate_panel`）。
- csindex 不含申万行业指数，行业腿的股息率仍为情景参数。
- 公开源存在延迟与不完整，结果仅用于内部研究（见页面与报告首页的免责声明）。
