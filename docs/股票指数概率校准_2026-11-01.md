# 股票与指数离线概率校准 · 2026-11-01

报告版本10增加可选的时间分隔概率校准。只用于离线研究，不替换页面模型、不按留出成绩选方法或调阈值。训练、校准、留出分开，是为了避免用模型训练标签再次拟合校准器；这也符合[scikit-learn校准说明](https://scikit-learn.org/stable/modules/calibration)的数据隔离要求。本实现是固定正则化的logit逻辑回归，不是直接调用 `CalibratedClassifierCV`。

## 时间协议

不配置 `calibration_start` 时沿用原协议：开发期滚动重估，留出开始前冻结方向模型。配置时必须满足 `start < development_start < calibration_start < holdout_start < end`，日期使用规范格式。

示例见[market-calibration-plan.json](market-calibration-plan.json)：

| 阶段 | 示例窗口 | 使用方式 |
| --- | --- | --- |
| 模型训练与开发评估 | 2021年起读预热，2022年起开发评估，2022-12-31截止 | 缩放及模型标签结束日均不越过截止日；开发评估目标也不跨入校准窗口 |
| 校准 | 2023-01-01至2024-12-31 | 使用已冻结模型的预测；只取窗口内成熟且按5/20周期隔开的标签 |
| 留出 | 2025-01-01至2026-10-30 | 模型、缩放器、校准系数均冻结；原概率与校准概率在同一成熟日期比较 |

校准窗口末端跨入留出期的标签一律排除。未来留出价格或概率不会改变校准系数。校准后的概率只在留出期输出；缺原预测仍缺失，无法校准时不静默回退为原概率。

启用校准后，方向模型比普通清单更早冻结，开发评估也提前结束；两种协议的收益和Brier不能混在一起排名。报告保留各自训练截止日、实际校准起止、最后标签结束日和源数据指纹。

## 固定算法与降级

输入概率裁剪到 `[0.000001,0.999999]` 后转为logit，只用校准窗口拟合 `LogisticRegression(C=1,max_iter=1000,random_state=0)` 的斜率和截距，无缩放、无自动调参。斜率必须为正；不把校准期间的负相关用于反转预测排名。

- 至少20个按周期隔开的校准观测，且正、负标签各至少5个，否则 `insufficient`。
- 校准分数没有变化时为 `degenerate`，拟合斜率非正为 `non_monotone`，达到迭代上限为 `non_convergent`。
- 成功为 `fitted`，保存斜率、截距与固定参数；以上门槛只控制展示，不保证校准有效性或统计功效。
- 概率越界、非有限值、日期不对齐或窗口重叠直接拒绝；没有足够校准数据时保留原因，`comparison=null`。

校准改变的是概率数值。Brier同时受概率可靠性和区分能力影响，Brier改善不能单独证明校准充分，更不代表买卖准确性或扣费收益提高。分组概率与真实频率也保留在配对结果中，稀疏分组不能支持强结论。

## 报告与执行

`result.calibration["5"/"20"]` 为五个固定特征版本各保存一条记录。成功后的 `comparison.base` 为该版本的原概率，`comparison.candidate` 为同一版本的校准概率；其成熟日期、Brier/HAC/块区间、分环境和固定阈值成交诊断复用既有实现。

60%买入/40%退出阈值、次会话开盘、三档费用、日历和账户约束保持相同。资金配置仍要求不复权股票，整手/最低佣金/容量传入校准对比，不使用线性仓位缩放。

计划比较数增加每证券5版本×2周期的10项，连同原16项一起计入Bonferroni家族；六证券为156项。即使校准失败，该项也不会从计划家族剔除。点态块区间仍未做多重区间校正，见[不确定性记录](股票指数不确定性诊断_2026-11-01.md)。

版本11的 `complete` 要求全部预定开发/留出对比满足样本门槛；`calibration_complete` 独立要求全部预定校准器拟合成功且每个留出配对至少20个成熟观测，空列表不算完成。任一不完整仍保存报告、CLI返回2，明细见[状态检查](验证完成状态检查_2026-11-01.md)。`--execution-only` 与校准配置同时使用会报错，避免静默忽略校准请求。
