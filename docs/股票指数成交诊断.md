# 股票与指数成交假设诊断

本轮把固定技术规则从“条件触发记录”接到可核对的账户模拟。股票、指数页面的技术分析下新增折叠区“规则信号 · 次会话成交与费用诊断”，对比规则与同区间买入持有的三档固定费用情景。

2026-11-01新增的离线资金账户见[资金情景验证](资金账户情景验证_2026-11-01.md)，支持整手、最低佣金和上一会话容量。下述归一化可分割模式仍为页面默认，历史验证记录按各轮原范围保留。

## 默认可分割账户约定

- 初始资本归一为1、初始空仓，目标仅为全仓或空仓，允许可分割单位。不支持卖空、杠杆、整手限制、最低佣金、税费明细、利息或资金容量。
- 每日收盘后的条件只能在下一会话开盘尝试执行；第一条日线没有此前订单，最后收盘的信号不假设未来成交。每天最多一个方向的成交，不做日内往返。
- 买入条件持续满足时可在下一会话再尝试；已受限订单当天失效，不跨未知会话保留。没有新条件时不产生新订单；同时满足买卖条件时减仓优先。
- 成交参考为下一会话开盘价；滑点作为固定价差冲击，费用按成交金额双边分别扣除。账户记录现金和持有单位，隔夜缺口只在原本持仓时计入收益。开盘成交资格不使用当日后续最高/最低价。
- 单边费用/滑点情景分别为0/0、10/5、30/10基点。这些是研究假设，不是实际券商或法定费率；同样订单路径下用于观察成本敏感性，不按结果选最优情景。
- 期末未闭合持仓按最后收盘估值，计入净收益和回撤，不虚构强制平仓。胜率、平均盈利/平均亏损比及利润因子只统计已闭合交易，未定义时显示“—”。
- 买入持有使用同样的会话和成交约定，在首条区间信号后的会话尝试建仓。策略与持有对照平均仓位不同，收益差不能解释为独立择时贡献。

页面输出净收益、最大回撤、成交次数、闭合交易数、胜率、盈亏比、年化双边换手、平均仓位、未成交次数及期末持仓状态。展开的运行明细可通过底层 `simulate_execution` 的逐笔记录检查信号日、成交日、参考开盘、冲击后有效价格与费用。

## 可选交易约束

离线CSV行情支持以下字段：

| 字段 | 处理方式 |
| --- | --- |
| `volume` | 0成交量时拒绝成交；负数或无穷值拒绝输入；缺失单独记录覆盖 |
| `limit_up` / `limit_down` | 开盘达到涨停价时不买入，开盘达到跌停价时不卖出；边界须为正、顺序正确且与OHLC同口径 |
| `buy_allowed` / `sell_allowed` | 明确为false/0时阻止对应方向；接受布尔、0/1或true/false字符串，非法值报错 |
| `is_session` | false表示已知非交易会话，不允许成交，也不能由该行发起订单 |

清单每项可加 `calendar_csv`，文件包含唯一、升序的 `date` 列。只使用行情实际起止范围内的日历，日历内缺失行情的日期保留为不可成交会话，只前向填充估值收盘，不填充可成交开盘。报告记录缺失会话、约束覆盖数与日历指纹。行情有日历之外的日期时拒绝该资产。

没有外部日历时仅按有效日线推进，无法分清休市、停牌或漏抓。没有涨跌停/买卖权限信息时采用可成交假设，不能据此宣称已经模拟真实成交。复权坐标并非原始报价；指数点位也需要另找对应ETF验证。页面明确显示这些缺口，不把缺字段当作“已核实可交易”。

### 线上数据接入现状（2026-11-08 核查）

上表 5 类字段中，**线上只有 `volume` 会被填充**：`market/analysis.py::clean_bars` 只保留 `open/close/high/low/volume/amount/turnover`，其余列在入口即被丢弃。`limit_up`、`limit_down`、`buy_allowed`、`sell_allowed`、`is_session` 是**离线 CSV 注入接口**，仓库内没有任何生产抓取器写入（全仓检索除读取/校验、前端覆盖率显示、文档与测试外没有赋值）；akshare 股票日线接口不返回历史涨跌停价或停牌标记。

不能由现有数据可靠推断涨跌停价：默认 `qfq` 复权价与基于未复权前收盘计算的涨跌停价不是同一口径；板块比例（主板 10% / 创业板·科创板 20% / 北交所 30%）、ST 5%、新股无涨跌幅限制都依赖时点元数据，代码库没有 ST 状态历史、上市日期或时点板块规则，代码前缀正则也不足以覆盖。因此**不会用推断值把 `constraint_data_available` 置为 true**：线上结果恒为 `false`，成交诊断页面明示「不能作为真实可执行性证据」。

真正接入是独立的数据工程项：新增可提供原始未复权报价、涨跌停价与停牌标记的行情源，升级 `market_v1_*` 缓存版本与 `clean_bars` 白名单，再补齐口径校验与回归；在此之前不宣称已模拟真实成交。

## 离线运行

```powershell
uv run python -m market_research.research.market_validation --manifest docs/market-validation-plan.json --output output/results/market-execution-new.json --execution-only
```

该模式只读取固定清单的本地行情，独立评估开发/留出区间的规则成交，不加载比较基准、不重训方向模型，也不改变股票/指数的方向概率。输出包含清单、源码与行情指纹及约束覆盖；报告文件拒绝覆盖。缺资产仍保留在报告中，并返回非零状态。

## 方向模型的固定概率阈值对比

原方向模型与波动、量价、相对强弱及全部新增特征候选，现均可进入成交诊断。固定规则为当日概率≥60%时发出下一会话买入目标，≤40%时发出退出目标，中间区间或缺少预测时没有新订单；不按概率大小直接缩放仓位。每天检查一次，不代表固定持有5/20日。阈值与三档费用情景预先固定，没有按本次留出收益优化。

每个候选与原模型使用双方首次共同可预测日作为起点，初始空仓；中途一方缺少预测时，两方都不发新订单，已有仓位仍保留并估值到同一请求截止日。买入持有也使用这个共同起点及相同成交约定。共同预测日数不是独立交易数，原模型在60%阈值下完全不交易也会如实显示零收益、零成交和无定义胜率，不被标记为数据缺失或有效获利。

成交评估使用已经发生的开盘与收盘，不要求5/20日方向标签已经成熟，因此成交截止日通常晚于Brier比较的最后成熟预测日。这两种样本量不能混用。不同候选可能因可预测起点不同而使用不同账户区间，仅可在各自共同口径内解释，不可跨候选直接排名。

页面新增“方向模型 · 固定概率阈值成交对比”，对应当前滚动训练历史。离线常规验证入口则在留出期冻结训练截止日，并将每一组配对成交结果写入方向报告：

```powershell
uv run python -m market_research.research.market_validation --manifest docs/market-validation-plan.json --output output/results/market-model-execution-new.json
```

清单的 `calendar_csv` 也会传递到方向模型成交评估并记录指纹。三个策略（原模型、候选、持有）×三档费用×四组候选×两个周期×两个阶段×六资产共864个预定账户摘要；缺少数据的计划不删除。Brier的多重比较近似仅对应方向误差，不是这864个收益摘要的显著性检验；当前未对扣费收益做选优或显著性判断。
