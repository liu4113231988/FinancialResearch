# 资金账户情景验证 · 2026-11-01

离线资金账户支持初始现金、整手、最低佣金、上一会话容量与部分成交。页面仍为原可分割诊断。最初只验证固定规则/持有，本轮已扩展到冻结留出期的方向模型；仅清单显式配置 `capital` 时启用。

## 输入契约

规则示例见[capital-validation-plan.json](capital-validation-plan.json)，长历史模型示例见[capital-model-validation-plan.json](capital-model-validation-plan.json)。清单每项可增加 `capital` 对象，同时必须为 `kind="stock"`、显式 `adjust=""`，复权价与指数点位被拒绝。使用 `--execution-only` 时只回放规则；不使用该标志时训练方向模型并输出资金对比，不再拒绝该资产。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| initial_cash | 100000 | 有限正数，初始现金 |
| lot_size | 100 | 成交数量的正整数单位，不允许分数股 |
| minimum_commission | 5 | 有限非负数，每次佣金取费率佣金与下限的较大者 |
| max_participation | null | 可选，大于0且不超过1，按上一完整会话成交量计算数量上限并向下取整到整手 |
| volume_unit | unknown | 容量限制开启时必须为 `shares`，不得把“手”默认为“股” |

这些数值是研究情景，不是交易所或券商规定。仍输出0/0、10/5、30/10bp费率/滑点情景；**资金账户中0bp仍可能收取最低佣金**，若要完全无佣金，需另把下限设为0。

## 执行与限制

- 收盘信号下一会话开盘尝试，每天最多一个方向，不借款、不卖空、不做日内往返。
- 买入数量同时满足现金支付金额及佣金、整手和容量限制；买不起一手则保留现金。
- 容量只用上一完整会话成交量，不用当日收盘后才知道的总量。上一会话缺失、已知非交易会话或单位不明时，不放行容量受限成交。
- 部分成交余额当天失效，后续需新目标才继续尝试；新增买入和分批卖出均独立计佣金下限。
- 全部清仓后才记一个闭合周期，按累计买入支出和卖出净收入算现金盈亏；资金模式的盈亏比与利润因子基于闭合周期现金盈亏。
- 期末收盘估值，不强制平仓。报告保存现金、持股、权益、费用、滑点、部分成交及阻断原因，底层函数另保留逐笔路径。
- 整手与最低佣金为非线性约束，资金模式明确禁用可分割账户的线性缩放仓位对照，保留同条件持有对照。

沿用日历、零成交量、显式权限及同口径涨跌停检查。上一日容量不保证集合竞价可成交；分红、拆分、税费细项、结算与微观容量尚未完整模拟，原始价结果不是总回报或券商流水复现。

## 方向模型资金账户扩展

原模型、各组候选和持有对照使用相同初始现金、整手、佣金、容量和日历。仍按60%买入/40%退出固定阈值逐日检查，配对取双方共同预测起点；中途缺预测时屏蔽双方新订单，已有持仓估值到同一截止日。开发期滚动训练，留出期冻结训练截止日，不把测试标签或缩放统计加入训练。

资金模式不使用线性缩放的仓位对照，不据测试收益自动挑模型。报告标注 `account_mode=capital`，保留零交易、资金不足和部分成交；`blocked_reasons`给出阻断原因计数。“有预测但买不起一手”属于已评估资金结果，不是假装缺预测。

原规则示例只从2025年取数据，冻结2025年底训练时可能不足以覆盖指标预热和252个成熟样本，不能直接用于模型验证。模型示例改从2021年取历史：

```powershell
uv run python run.py market-snapshot --manifest docs/capital-model-validation-plan.json --output-dir output/capital-model-snapshot-new --fetch-missing --calendar
uv run python run.py market-validate --manifest output/capital-model-snapshot-new/manifest.json --output output/results/capital-model-validation-new.json
```

这些是原始价的预测和账户情景，不是含分红总回报。整手、容量、最低佣金及当前数据版本会使资金结果与归一化账户不同，不能混用两类报告直接排名。

资金模式的持有对照每日发出满仓目标，以同样的整手、资金和容量规则尝试投入现金并维持持有。首日不保证全部成交；剩余现金后来可买一手时可能继续投入，属于持续满仓目标持有，不能误读成保证首日全仓的一次性成交。
