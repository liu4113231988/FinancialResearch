## 固定计划与运行

默认清单位于 [market-validation-plan.json](market-validation-plan.json)，含4只股票、2个指数。2021年开始读取预热数据，2023年起为开发评估，2025年起至2026-10-30为留出区间。这个小样本属于演示证券固定清单，不代表全市场。该日期划分是回顾性研究设计，不能宣称已经事前预注册或从未看过这段历史。

```powershell
uv run python -m market_research.research.market_validation --manifest docs/market-validation-plan.json --output output/results/market-validation-new.json
```

入口只读本地同步缓存，不联网、不提交分析任务。缓存缺失、截止覆盖不足或数据非法时保留证券与原因，不将其从清单剔除。输出不存在的父目录会创建；已存在的报告拒绝覆盖，后续试验需使用新文件名。清单参数错误报错；样本未完整覆盖时仍保存报告并返回非零状态。

清单的每项可指定相对于清单目录的 `csv` 和 `benchmark_csv`，以使用固定快照代替本地缓存。CSV包含 `date,open,high,low,close`，可选 `volume,amount,turnover`；日期须唯一且升序。股票注明 `adjust`，价格必须为同一口径且有限、为正。指数缺少换手率时不会强行补零；整个特征组都无来源时标注不可用。

## 对比口径

- 固定候选为原模型、原模型加波动、加量价、加相对强弱、全部新增特征；记录实际特征清单，不按测试成绩调参或自动选优。
- 开发期按既有节奏滚动重估；进入留出期时，将训练特征与其标签结束日均限制在留出开始之前。留出期输入只使用当前及此前行情，训练和缩放统计不使用留出标签。
- 分别评估5/20个有效日线周期，按预测周期抽取非重叠起点。开发区间末尾跨入留出期的目标不计入开发评估，留出末尾未成熟标签也不计入。
- 每个候选与原模型只在双方都能预测的共同成熟日期比较。候选间可能因缺字段而样本不同，不能直接用各自Brier排名。
- 展示准确率、Brier、概率分组及基准偏强/偏弱/分歧/未知的分组结果；环境归属使用信号日的基准MA60与20日动量，未知环境单列。每组少于20笔时不判断优劣。
- 探索性统计使用配对Brier差的HAC正态近似，最多5阶滞后；按完整预定家族（资产数×4候选×2周期×2阶段）做Bonferroni校正，缺数据的试验仍计入家族。样本少于20笔或差值方差退化时不报告p值。近似p值不构成严格显著性保证。

报告保存清单、清单哈希、行情/基准内容指纹、源码指纹及Python/pandas/numpy/sklearn版本。重复查看或依据留出表现修改设计后，应将这段区间视作已被使用，后续需要新的最终验证数据。

## 实际执行与限制

2026-10-31已执行六证券清单的本地缓存回放。报告保存在 `output/results/market-validation-20261031-v2.json`，该目录为本地运行产物，不随Git分发。v1保留为初始试验记录；v2修正可选成交字段缺失导致整组候选不可用的问题，保留所有试验结果。

目前三只股票的缓存未覆盖清单截止日，不能把其缺失当作通过。已有结果存在改善和退步，不据单证券、单周期结果宣称普遍提高准确率，也不自动启用胜出的模型。

本地v2结果中，全部新增特征相对原模型的Brier改善如下（正值为误差降低，负值为退步）：

| 证券 | 5日 · 88笔 | 20日 · 22笔 |
| --- | --- | --- |
| 贵州茅台 sh600519 | +0.0001 | +0.0026 |
| 沪深300 sh000300 | −0.0064 | −0.0095 |
| 创业板指 sz399006 | −0.0461 | −0.0280 |

平安银行、宁德时代、中国平安因缓存未覆盖截止日未评估。三项可评估资产的所有候选在本次HAC/Bonferroni近似诊断中均未通过0.05门槛。该结果不支持直接替换原模型；本轮只建立验证能力并记录当前数据版本下的表现。

固定规则与方向模型固定概率阈值的次会话开盘及费用情景框架已实现，见[成交诊断](股票指数成交诊断.md)。常规方向报告保存每个候选与原模型在共同可预测区间的成交摘要，包含零交易和亏损结果。固定样本现已补齐；后续仍需扩大代表性样本、加入未来未使用区间、历史停牌/涨跌停和实际ETF约束。概率对比与账户模拟仍是两种不同证据。
